# PixRetribution 循环与思路

依据当前 [rotation.py](../pix/rotation.py) 整理。字段含义见 [layout.md](layout.md)，动作绑定见 [keymap.md](keymap.md)。

## 循环思路

先打断与自保，再处理爆发、四件套触发、圣能消耗和资源生成。单体与多目标使用同一条从上到下的规则链，不独立维护两套循环。

## 状态与门控

插件关闭、延迟中、死亡、脱战、载具、输入、地面选点、施法／引导／蓄力、当前目标无效时等待。因此打断和自保也要求有效当前目标。进攻范围主要参考制裁之锤；责难使用自身射程。

未强制单体且可观察近战敌人数≥2为多目标；强制单体或敌人数恰好1为单体。敌人数为0且未强制单体时，两分支都不成立。

## 动作优先级

| 顺序 | 动作 | 条件与思路 |
| --- | --- | --- |
| 1 | 责难 | 就绪，按焦点、目标顺序检查非友方、射程和可打断条件 |
| 2 | 圣疗术 | 自身血量≤20%，就绪 |
| 3 | 圣盾术 | 自身血量≤15%，就绪 |
| 4 | 荣耀圣令 | 自身血量≤60%，圣能≥3 |
| 5 | 治疗石、生命药水 | 自身血量≤30%，依次检查物品可用性 |
| 6 | 清毒术 | 自动清毒开启、可驱散中毒或疾病、技能就绪 |
| 7 | 圣光潜力 | 独立爆发药水开关开启且药水可用，不要求爆发窗口 |
| 8 | 上饰品、下饰品 | 自动饰品开启、爆发中、目标在进攻范围 |
| 9 | 复仇之怒 | 就绪且爆发中；此分支不另检查进攻范围 |
| 10 | 处决宣判 | 就绪、有复仇之怒、目标在范围 |
| 11 | 四件套触发消耗 | 四件套开启、有神圣意志、无神圣仲裁风暴：多目标用最终审判，单体用神圣风暴 |
| 12 | 常规消耗 | 圣能≥4：多目标神圣风暴，单体最终审判 |
| 13 | 灰烬觉醒 | 就绪、圣能≤2 |
| 14 | 晨光消耗 | 圣能≥3且有晨光：多目标风暴，单体审判 |
| 15 | 圣洁鸣钟 | 就绪且有复仇之怒 |
| 16 | 审判 | 2充能、圣能≤2、多目标 |
| 17 | 公正之剑 | 就绪且无战争艺术 |
| 18 | 审判 | 2充能、圣能≤2、单体 |
| 19 | 重复消耗检查 | 按代码保留多目标四件套、4圣能风暴、单体四件套、4圣能审判检查；相同条件通常已被前序规则命中 |
| 20 | 审判 | 充能≥1、圣能≤2 |
| 21 | 公正之剑 | 就绪、圣能≤3 |
| 22 | 审判 | 充能≥1、圣能≤4 |
| 23 | 最后消耗 | 圣能≥3：多目标风暴，单体最终审判 |

第11–23项均要求目标在进攻范围。表中的“单体审判／多目标风暴”消耗指最终审判／神圣风暴，与生成圣能的审判技能区分。

## 专属约定

四件套触发时的技能选择与普通消耗相反，不能在整理时交换。处决宣判和鸣钟读取复仇之怒增益；复仇之怒本身读取爆发窗口。保留当前规则顺序，文档整理不消除代码中的重复分支。

圣光潜力可用表示 241308／241309 任一品阶有非银行库存且冷却就绪。两种品阶分别计数，保留原宏顺序和药水优先级。输出模式提示与人数计算均采用制裁之锤 853 范围内可观察敌人数。
