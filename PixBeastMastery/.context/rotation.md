# PixBeastMastery 循环与思路

依据当前 [rotation.py](../pix/rotation.py) 整理。字段含义见 [layout.md](layout.md)，动作绑定见 [keymap.md](keymap.md)。

## 循环思路

核心 DPS 优先级与打断、自保、宠物管理分别说明。每轮执行首个满足条件的动作。

## 状态与动作优先级

每次只执行第一个满足条件的动作。启停、手动延迟、死亡、坐骑/载具、聊天、地面选点和施法/引导/蓄力会暂停自动动作。

1. **恢复宠物**：缺宠或死宠时，移动则等待站定，站定后执行召唤/复活宏；位于战斗和目标判断之前。
2. **自动误导**：只在非团队小队、脱战时执行。要求学会误导、冷却好。先按 party1–4 取第一位存在、存活且在线的坦克，再检查该坦克是否在误导射程内；超距不改选后续坦克，不要求攻击目标，冷却好就可再次释放。
3. **战斗门控**：此后的打断、自保、输出和治疗宠物均要求玩家在战斗，且当前目标存在、存活、可攻击。
4. **反制射击**：按焦点、鼠标指向、目标顺序判断；自身冷却好、单位在射程、可打断、图标不在黑名单，且已过施法进度严格大于配置阈值。鼠标指向与目标打断还受各自开关控制。
5. **自保**：生命≤30%先治疗石，再银月城生命药水241304；生命≤50%时意气风发。其他防御技能由玩家控制。
6. **爆发药水**：爆发窗口内、目标在反制射击范围、药水开关开启且鲁莽药水可用时使用。
7. **输出**：按下面的优先级执行，所有进攻技能都参考反制射击147362射程。
8. **治疗宠物**：最低优先级；宠物存在、存活、生命<70%，且治疗宠物冷却好。脱战或没有有效当前目标时不执行。

敌人数只统计可观察姓名板中可攻击、存活、进入战斗且在147362射程内的单位，不代表所有附近敌人。自动模式人数≥2走AOE，0或1走单体；强制模式覆盖此判断。

| 顺序 | 输出条件 |
| --- | --- |
| 狂野怒火（AOE） | AOE、非收尾、冷却好，且玩家存在野兽顺劈268877、剩余时间严格大于2秒；先检查自动饰品再怒火，优先于倒刺和鞭笞 |
| 倒刺射击 | 技能可用，且下一层充能恢复<2秒；单体时狂野怒火冷却<3秒也满足 |
| 狂野鞭笞 | AOE、集中值≥35、冷却好 |
| 狂野怒火（单体） | 单体、非收尾、冷却好；不要求野兽顺劈，先检查自动饰品再怒火 |
| 杀戮命令 | 单体和AOE共用：冷却为0、有充能、集中值≥30，且玩家存在龙471878／猪472324／熊472325／自然之友1276720任一增益 |
| 眼镜蛇射击 | 集中值≥35、有眼镜蛇利牙1299389，且单体或狂野鞭笞冷却>0 |
| 倒刺射击 | 技能可用 |
| 眼镜蛇射击 | 集中值≥35，且单体或狂野鞭笞冷却>0 |

AOE 无野兽顺劈时不释放狂野怒火。

自动饰品仅在到达单体或 AOE 的怒火分支、满足该分支全部条件时检查，不要求爆发窗口。开启自动饰品后，优先使用可用上饰品，其次可用下饰品；关闭自动饰品或无可用饰品时直接释放怒火。每轮只执行一个动作，下一轮重新判断全部条件，不等待饰品冷却，也不锁定后续怒火。因此单体提前倒刺仍优先于饰品；收尾、怒火冷却未好或 AOE 顺劈不足时不会自动使用饰品。

首领战等同于第86格的遭遇战状态，自动模式在遭遇战中始终不收尾。非遭遇战时使用现有目标预测生命比例，每轮判断是否严格低于配置阈值；恰好等于阈值不收尾，切换目标或血量恢复后重新判断。插件与Python须配套更新第60格三态协议及第87格阈值。集中值百分比由配置上限还原；配置错误会影响30/35点阈值判断。缺失冷却数据不视为就绪；满充能通过充能数量及上限识别。

## 专属约定：鞭笞与怒火

用户于 2026-10-02 提供并确认的高手总结：狂野鞭笞会增强狂野怒火，因此 AOE 时怒火要等鞭笞，且应是鞭笞后的第一个输出技能。这是本项目采用的经验，不是 Maxroll 原文；不能仅因其简化优先级把怒火列在前面，就将此顺序改回。

用户指定以玩家增益 **268877 / Beast Cleave / 野兽顺劈** 作为 AOE 怒火的判断条件。

## 当前实现

- AOE：顶部“狂野怒火增益期间优先鞭笞”的条件及动作已整段注释，保留代码、第 84 格及其 Context 属性和插件加载项。后面的常规狂野鞭笞分支仍要求集中值至少 35、鞭笞冷却为 0。
- AOE：狂野怒火冷却就绪、未处于收尾状态（`Isfinishing=False`）、玩家存在野兽顺劈，且野兽顺劈剩余时间严格大于 2 秒时，先检查自动饰品再释放狂野怒火。该分支是当前核心 DPS 的最高优先级，高于倒刺射击和常规狂野鞭笞分支。不再检查鞭笞冷却；恰好 2 秒不满足条件。
- AOE 没有野兽顺劈时不释放狂野怒火，即使鞭笞正在冷却。
- 单体：保留原位置的狂野怒火分支，只要求冷却就绪、未处于收尾状态（`Isfinishing=False`），不要求野兽顺劈；符合提前条件的倒刺仍在它之前。
- 依据当前增益状态及剩余时间判断，不追踪上一技能，也不把“增益存在”解释为“刚刚释放了鞭笞”。满足条件的怒火先于常规鞭笞分支释放。
- 沿用现有战斗、目标和射程门控，其余输出技能顺序不变。

## 三态收尾与血量阈值

第60格使用配置枚举，灰度0自动、10残血持续爆发（关闭收尾）、20残血不爆发（开启收尾）。`Context.finishing` 返回整数模式，`rotation.py` 每轮计算局部变量 `Isfinishing`，单体与AOE的狂野怒火均要求该变量为False。

- 自动（默认）：首领战等同于第86格 `encounter_in_progress`，遭遇战中始终不收尾；否则，目标预测生命比例 `target_health_pct` 严格低于第87格 `finishing_health_threshold` 时收尾。异常模式值按自动处理。
- 残血持续爆发（关闭收尾）：始终不收尾，狂野怒火仍按原有施放条件使用。残血不爆发（开启收尾）：名称仅为显示文案，实际仍始终收尾，包括遭遇战中；两者均不受血量阈值影响。
- 阈值默认20%，范围0–50%，滑块步进5；恰好等于阈值不收尾，0表示自动模式不收尾。每轮重新判断，切换目标、血量恢复不会保留此前状态。
- 收尾禁止狂野怒火及其前置自动饰品，不改变倒刺射击等其他技能的优先级，也不影响药水。
- 模式脱战、重载恢复自动，阈值与按钮位置持久化保存。按钮及 `/pix end toggle` 按自动→残血持续爆发→残血不爆发循环，`/pix end auto|off|on` 可直接指定。

第87格用灰度字节直接表示阈值，Python四舍五入读取，超出0–50回退20，合法的0保留。基板扩为356px，插件与Python必须配套更新。

## 状态读取

第 76 格通过原生 AuraContainer 显示玩家野兽顺劈：存在为白色，不存在为黑色。Python 通过 `Context.player_has_buff_beast_cleave` 读取，插件与 Python 必须配套更新。

第 84 格以相同方式显示玩家狂野怒火增益 19574，通过 `Context.player_has_buff_bestial_wrath` 读取。更新插件后需在游戏内 `/reload`，并让 Python 重新定位扩展后的基板。

第 85 格通过 AuraContainer 的 DurationText 原生绑定和 `AuraRemaining` 曲线显示玩家野兽顺劈剩余时间，由 `Context.player_buff_beast_cleave_remaining` 解码为秒。0 表示不存在或到期，240 包含永久光环或上限饱和；实际阈值判断受渲染与采样影响。
