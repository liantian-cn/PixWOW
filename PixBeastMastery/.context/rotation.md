# PixBeastMastery 循环与思路

依据当前 [rotation.py](../pix/rotation.py) 整理。字段含义见 [layout.md](layout.md)，动作绑定见 [keymap.md](keymap.md)。

## 循环思路

核心 DPS 优先级与打断、自保、宠物管理分别说明。每轮执行首个满足条件的动作。

## 函数结构

`Rotation` 按六类职责拆分，`main_rotation` 依次调用 `check_pause(ctx)`、`precombat_rotation(ctx)`、`defensive_rotation(ctx)`、`interrupt_rotation(ctx)`，再计算 `is_aoe` 和 `is_finishing`，调用 `aoe_rotation(ctx, is_finishing)` 或 `single_target_rotation(ctx, is_finishing)`。分类方法未匹配返回 `None`；返回任何动作，包括 `Idle`，都立即结束本轮。

`check_pause` 检查全局暂停条件。`precombat_rotation` 每轮都会调用，依次处理宠物恢复、脱战误导、战斗和有效目标检查；宠物恢复不限定脱战。两段输出分别展开完整规则，先检查攻击射程，再检查爆发药水及技能优先级。模式计算与最后的治疗宠物保留在入口，输出方法返回 `None` 后仍可检查治疗宠物，包括目标超出攻击射程的情况。

## 状态与动作优先级

每次只执行第一个满足条件的动作。启停、手动延迟、死亡、坐骑/载具、聊天、地面选点和施法/引导/蓄力会暂停自动动作。

1. **恢复宠物**：缺宠或死宠时，移动则等待站定，站定后执行召唤/复活宏；位于战斗和目标判断之前。
2. **自动误导**：只在非团队小队、脱战时执行。要求学会误导、冷却好。先按 party1–4 取第一位存在、存活且在线的坦克，再检查该坦克是否在误导射程内；超距不改选后续坦克，不要求攻击目标，冷却好就可再次释放。
3. **战斗门控**：此后的打断、自保、输出和治疗宠物均要求玩家在战斗，且当前目标存在、存活、可攻击。
4. **自保**：生命≤30%先治疗石，再银月城生命药水241304；生命≤50%时意气风发。自保优先于打断，其他防御技能由玩家控制。
5. **反制射击**：自保未命中后，按焦点、鼠标指向、目标顺序判断；自身冷却好、单位在射程、可打断、图标不在黑名单，且已过施法进度严格大于配置阈值。鼠标指向与目标打断还受各自开关控制。
6. **爆发药水**：爆发窗口内、目标在反制射击范围、药水开关开启且第54格就绪时使用共用爆发药水宏，依次尝试狂放恣意饮剂241293、241292，再尝试鲁莽药水241288、241289。任一物品有库存、冷却启用且已结束即就绪；不新增独立检测格或宏。
7. **输出**：按下面的优先级执行，所有进攻技能都参考反制射击147362射程。
8. **治疗宠物**：最低优先级；宠物存在、存活、生命<70%，且治疗宠物冷却好。脱战或没有有效当前目标时不执行。

敌人数只统计可观察姓名板中可攻击、存活、进入战斗且在147362射程内的单位，不代表所有附近敌人。自动模式人数≥2走AOE，0或1走单体；强制模式覆盖此判断。

| 顺序 | 输出条件 |
| --- | --- |
| 1. 狂野鞭笞 | AOE、鞭笞冷却为0、怒火施放后4秒窗口剩余>0；不检查集中值，不足时也持续选择鞭笞 |
| 2. 狂野鞭笞 | AOE、鞭笞冷却为0、集中值≥35 |
| 3. 眼镜蛇射击 | AOE、集中值≥35、有野兽顺劈268877且无狂野怒火19574增益，且利牙层数>2 |
| 4. 倒刺射击 | 倒刺充能≥1、怒火冷却<3秒；单体和AOE均适用 |
| 5. 倒刺射击 | 倒刺充能≥1、下一层充能恢复<4秒；满充能时恢复时间读取为0 |
| 6. 狂野怒火（AOE） | AOE、怒火冷却为0、未收尾、顺劈剩余>1秒；先检查自动饰品，不附加顺劈存在布尔条件 |
| 7. 狂野怒火（单体） | 单体、怒火冷却为0、未收尾；先检查自动饰品 |
| 8. 眼镜蛇射击 | 集中值≥35、有野兽顺劈、利牙层数>2 |
| 9. 杀戮命令 | 杀戮充能≥1、集中值≥30，且自然之友／猪／熊／龙增益任一存在 |
| 10. 倒刺射击 | 倒刺充能≥1 |
| 11. 眼镜蛇射击 | 集中值≥35 |

倒刺和杀戮均以充能判断可用，不额外检查自身冷却。上表均继承战斗、有效目标和射程门控。严格比较不包含边界：怒火冷却恰好3秒、倒刺恢复恰好4秒、顺劈剩余恰好1秒均不满足对应提前或怒火条件，但可继续命中后续规则。

自动饰品仅在到达单体或 AOE 的怒火分支、满足该分支全部条件时检查，不要求爆发窗口。开启自动饰品后，优先使用可用上饰品，其次可用下饰品；关闭自动饰品或无可用饰品时直接释放怒火。每轮只执行一个动作，下一轮重新判断全部条件，不等待饰品冷却，也不锁定后续怒火。因此前序鞭笞、眼镜蛇及提前倒刺命中时均优先于饰品；收尾、怒火冷却未好或 AOE 顺劈不足时不会自动使用饰品。

首领战等同于第86格的遭遇战状态，自动模式在遭遇战中始终不收尾。非遭遇战时使用现有目标预测生命比例，每轮判断是否严格低于配置阈值；恰好等于阈值不收尾，切换目标或血量恢复后重新判断。插件与Python须配套更新第60格三态协议及第87格阈值。集中值百分比由配置上限还原；配置错误会影响30/35点阈值判断。缺失冷却数据不视为就绪；满充能通过充能数量及上限识别。

## 专属约定：杀戮命令

按用户本次确认，单体和AOE均允许自然之友1276720、猪472324、熊472325、龙471878任一存在时使用杀戮，同时要求充能≥1、集中值≥30，不限制利牙层数。此规则替代此前仅自然之友的当前策略；历史木桩记录保留在更新日志，不作为本次组合规则的实测结果。

## 专属约定：鞭笞与怒火

AOE首先检查怒火施放后4秒窗口内的鞭笞，不检查集中值；即使暂时无法成功施放，也返回鞭笞动作，不跳到后续输出。窗口保持独立计时，不因插入打断或选择鞭笞而消费或清零。

常规鞭笞需要集中值≥35，位于怒火之前。AOE怒火要求顺劈剩余严格大于1秒，不额外检查顺劈存在布尔值；单体怒火不要求顺劈。怒火不再是AOE核心DPS最高优先级，前面的鞭笞、眼镜蛇和倒刺条件命中时先执行这些动作。

第3条眼镜蛇要求AOE、集中值≥35、有顺劈、无怒火增益且利牙>2，恰好2层不满足；第8条要求有顺劈和利牙>2，不区分单体/AOE；最后的眼镜蛇仅要求集中值≥35。眼镜蛇不再附加鞭笞正在冷却的条件。

## 三态收尾与血量阈值

第60格使用配置枚举，灰度0自动、10残血持续爆发（关闭收尾）、20残血不爆发（开启收尾）。`Context.finishing` 返回整数模式，`main_rotation` 在进入输出分支前计算局部变量 `is_finishing` 并传入输出方法，单体与AOE的狂野怒火均要求该变量为False。

- 自动（默认）：首领战等同于第86格 `encounter_in_progress`，遭遇战中始终不收尾；否则，目标预测生命比例 `target_health_pct` 严格低于第87格 `finishing_health_threshold` 时收尾。异常模式值按自动处理。
- 残血持续爆发（关闭收尾）：始终不收尾，狂野怒火仍按原有施放条件使用。残血不爆发（开启收尾）：名称仅为显示文案，实际仍始终收尾，包括遭遇战中；两者均不受血量阈值影响。
- 阈值默认20%，范围0–50%，滑块步进5；恰好等于阈值不收尾，0表示自动模式不收尾。每轮重新判断，切换目标、血量恢复不会保留此前状态。
- 收尾禁止狂野怒火及其前置自动饰品，不改变倒刺射击等其他技能的优先级，也不影响药水。
- 模式脱战、重载恢复自动，阈值与按钮位置持久化保存。按钮及 `/pix end toggle` 按自动→残血持续爆发→残血不爆发循环，`/pix end auto|off|on` 可直接指定。

第87格用灰度字节直接表示阈值，Python四舍五入读取，超出0–50回退20，合法的0保留。当前基板包含第88格，宽360px，插件与Python必须配套更新。

## 状态读取

第88格监控玩家成功施放狂野怒火19574后的本地4秒窗口，通过`Context.bestial_wrath_cast_remaining`读取剩余秒数。只监听player的`UNIT_SPELLCAST_SUCCEEDED`，可读法术ID匹配后启动或重置4秒；秘密、缺失或其他ID忽略且保留已有计时，不回退冷却事件。插入打断、其他技能、切目标和脱战均不清除窗口；初始化、重载和进入世界清零。使用截止时间计算，每0.1秒刷新，灰度字节为剩余秒数乘10向上取整，Python除10还原；量化高估小于0.1秒，显示另受刷新和卡顿影响。这不是怒火增益剩余时间；剩余大于0用于AOE最高优先级鞭笞条件。更新插件后执行`/reload`并重新定位360×12基板；战斗中事件ID的可读性需实机确认。

第 59 格通过 AuraContainer 的 SetApplicationCount 绑定共享 CountFormatter，显示玩家眼镜蛇利牙1299389层数。`Context.player_buff_stacks_cobra_fangs`按灰度字节四舍五入读取整数，0包含无光环或无计数，255表示至少255层；`player_has_buff_cobra_fangs`由层数大于0派生。当前循环以利牙>2配合顺劈触发第8条眼镜蛇，杀戮不限制利牙层数；第3条AOE眼镜蛇要求利牙>2。第59格由布尔改为计数，插件与Python必须配套更新，更新插件后执行`/reload`并重启Python；基板尺寸不变。

第 76 格通过原生 AuraContainer 显示玩家野兽顺劈：存在为白色，不存在为黑色。Python 通过 `Context.player_has_buff_beast_cleave` 读取，插件与 Python 必须配套更新。

第 84 格以相同方式显示玩家狂野怒火增益 19574，通过 `Context.player_has_buff_bestial_wrath` 读取。更新插件后需在游戏内 `/reload`，并让 Python 重新定位扩展后的基板。

第 85 格通过 AuraContainer 的 DurationText 原生绑定和 `AuraRemaining` 曲线显示玩家野兽顺劈剩余时间，由 `Context.player_buff_beast_cleave_remaining` 解码为秒。0 表示不存在或到期，240 包含永久光环或上限饱和；实际阈值判断受渲染与采样影响。
