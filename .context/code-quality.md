# 代码质量控制

## 业务条件注释

Rotation 的每个业务条件前说明条件与结果，使用 `# 如果 …` 和 `# => …`。涵盖门控、技能分支、嵌套目标选择、辅助函数、推导式、条件表达式和布尔派生状态；纯技术防空无需套格式。

写清与／或关系、严格或非严格比较、单位、目标、优先顺序及继承的外层条件。不能用一段总说明替代不同分支的注释，也不编造策略理由。整理注释不能交换规则、删除重复分支或改变宏目标。

```python
# 如果 焦点有效、不可协助且在心灵冰冻射程内
# 如果 施法通过打断过滤，已过进度严格大于配置阈值，且心灵冰冻就绪
# => 对焦点施放心灵冰冻
```

## Lua cells 文件头

所有项目 `pix/lua/cells/` 下的 Lua 文件按以下顺序组织文件头，业务逻辑放在这些段落之后：

1. 插件声明：`local addonName, addonTable = ...`，作为首个代码段。
2. `-- Lua 内置方法`：Lua 内置函数及标准库方法的 local 别名，例如 `table.insert`、`math.random`。
3. `-- WoW API`：WoW 全局 API 及命名空间方法的 local 别名，例如 `CreateFrame`、`C_Timer.After`。
4. `-- 项目引用`：来自 `addonTable` 的稳定函数、类型、对象和表引用。
5. `-- 本地配置`：坐标、ID、阈值、配置表和初始对象声明，例如 `X`、`cell`、`eventFrame`。

允许在插件声明前保留文件功能说明。没有内容的段落省略；其余段落使用上述统一中文注释，段间一个空行，不强制等号对齐。不要为凑齐空段落引入未使用的方法或对象别名。

稳定方法和项目引用必须集中本地化，业务代码使用别名。会重新赋值的状态、延迟初始化且在文件加载时尚不可用的对象保留动态访问，并就原因作注释；不能为满足风格而缓存旧值或 nil。稳定表引用集中本地化，表内动态字段仍在使用时读取。方法接收者调用（如 `cell:setCell(...)`）保持其对象语义，不要求把对象方法拆成独立函数别名。

计时器、缓存等运行状态允许在对应逻辑前就近声明；函数内部局部变量保持原位。不能仅因业务函数后出现 local 就判定违规。整理声明时保持初始化时序、作用域、调用方式和现有行为。

```lua
local addonName, addonTable = ...

-- Lua 内置方法
local insert = table.insert
local random = math.random

-- WoW API
local CreateFrame = CreateFrame
local After = C_Timer.After

-- 项目引用
local Cell = addonTable.Cell
local UIInitFuncs = addonTable.UIInitFuncs

-- 本地配置
local X = 22
local cell
local eventFrame = CreateFrame("Frame")

-- 以下为业务逻辑；仅为文件头示例，未展示更新和初始化实现。
```

审计逐文件核对声明归类、顺序、本地化、段注释和空行。动态访问是否属于例外，应追踪对象的初始化和赋值位置后判断；示例文件只作结构参考，不豁免其自身可能存在的格式问题。

## 动态显示刷新

所有动态 Cell、ValueBar、配置开关／阈值和动态图标，都需要间隔不超过 1 秒的刷新兜底。初始化、事件延后回调和配置回调本身不算周期兜底。保留事件快速响应及已有的 0.05／0.1／0.2 秒等更快轮询，不重复添加计时器或降速。

审查须追踪共享 helper、计时器的调用链、生命周期及显示状态，不能只凭单文件没有 OnUpdate 判定缺失。兜底调用复用当前更新函数；黑名单图标的周期重绘复用已选 ID，不每秒重新请求全部法术资源。

静态输出不需要轮询。AuraContainer 的原生光环绑定和 DurationText 原生更新路径豁免；其中自定义的单位资格或显隐门控仍要单独满足刷新要求。单位换绑、同 token 换人、目标消失和光环移除时，应更新或清空相应输出。

新增代码避免重复扫描、频繁临时分配、重复计时器和无关单位刷新；报告性能问题须指出具体调用路径，没有测量时不称为实测瓶颈。必要的显示计算和普通聚合不是业务循环越界。

## 验证

只运行改动相关检查。普通修改不新增测试文件；排错先确定原因，必要时使用临时内存场景或一两个针对性回归案例。五项目包必须保持独立执行环境，不放在同一导入路径中。

```powershell
uv run --locked pyright PixBlood/pix
uv run --locked --directory PixBlood python -m compileall -q pix
git diff --check
```

项目名按实际改动替换。Python 静态检查不证明 Lua 或客户端显示正确；报告实际执行的检查及范围。已有用户使用确认按[API 与解析约定](wow-api-notes.md)采用，不把相同实现重新描述成毫无依据的路线。编码、字体、单位绑定或采样条件改变时，再检查相应状态转换。

仅任务需要时启动 GUI、截图诊断或安装插件；游戏内显示验证使用匹配插件及 `/reload`。构建脚本可用性以根 AGENTS 的当前约定为准。

代码保持四空格缩进和 LF。新增 Python 函数用 snake_case、类用 PascalCase；不为命名统一重构既有接口。Lua 遵循邻近文件风格、addonTable 共享状态及 TOC 初始化顺序。
