# PixBlood 循环与思路

依据当前 [rotation.py](../pix/rotation.py) 整理。字段含义见 [layout.md](layout.md)，动作绑定见 [keymap.md](keymap.md)。

## 循环思路

优先低血量自疗与打断，然后维护白骨之盾，消耗符文和符能。攻击技能的可切换单位规则先目标、后焦点；心灵冰冻先焦点、后目标；两者都不在对应射程内才继续下一条。当前目标必须有效，即使焦点有效也不能绕过最前面的目标门控。

## 状态与门控

插件关闭、延迟中、脱战、正在施法或引导、蓄力、当前目标不存在／死亡／不可攻击时返回空闲。近战技能使用各单位近战范围；死神的抚摩使用远程范围。焦点还须存在、存活、可攻击。

## 专属约定

枯萎凋零宏始终在玩家脚下施放；鼠标单位射程仅是其中一条规则的条件。打断条件由 Context 与黑名单共同决定，规则中的进度使用已过施法进度。键位的 F12 保留约定见 [keymap.md](keymap.md)。

符能由 Context 提供 `power_runic_power_ratio`（0–1），循环每轮计算 `power_runic_power = ctx.power_runic_power_ratio * 125`。125 是当前版本支持天赋的固定上限；42／80 点阈值及优先级保持不变。圣光潜力支持 241308／241309，任一品阶有非银行库存且冷却就绪即可满足药水可用条件。
